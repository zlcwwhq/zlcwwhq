## 03 / Currently exploring

### Vibe Coding

I'm curious about the dialogue between human ideas and AI-generated code: how an initial intention becomes a working prototype, and how iteration improves the result.

Questions I'm exploring:

- How can I describe an idea clearly enough for AI to help build it?
- Where does AI speed up development, and where does engineering judgment matter most?
- How can I keep the resulting code understandable, testable, and maintainable?
